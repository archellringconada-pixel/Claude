Pillar 2

AI Automation & Technical Operations

I'm actively building deep expertise in AI automation, working hands-on with real client systems using tools like n8n, Claude Code, and workflow automation platforms. Here's real, measured work from current client projects.

Tools used: WooCommerce, Elementor, GoHighLevel, Airtable, Boost.space/Make, GA4, Search Console, Claude Code

Finding the cause of a months-long server slowdown

Challenge
Server load high since early September; first-byte times up to 5.7s on uncached pages.
What I did
Diagnosed with the hosting provider, traced a hanging cart-refresh request to one plugin hook sending a pointless tracking ping on nearly every page view, and removed it with a small reversible fix.

Result: Cart refresh request went from 534–586s to 1–1.3s. No hosting upgrade needed.

Making product pages usable on a phone

Challenge
Product pages froze for 4.6s on mobile; ~1.2MB of unused JavaScript loading.
What I did
Removed unused scripts on product pages only, with a full regression check (checkout, add-to-cart, analytics events) before redeploying.

Result: Total blocking time 4,590ms → 360ms (−92%), performance score 30 → 49, JS execution time 9.4s → 2.2s, page weight 9.4MB → 6.7MB.

Stock sync automation + back-in-stock waiting list

Challenge
Owner updated quantities in Airtable but nothing pushed to the website — risk of overselling or wrongly hiding products.
What I did
Built an automatic push (Airtable edit → Boost.space/Make → WooCommerce update), tested end to end, and added a back-in-stock waitlist with automatic discount codes.

Result: 29 products corrected on first run, then 168/172 then 160/160 matching with zero differences; every automated run has succeeded since launch.

Making analytics numbers trustworthy

Challenge
Reports looked healthy but were misleading — 99.9% engagement included large bot traffic.
What I did
Cleaned up tracked events, found ~51% of sessions were overseas bots, rebuilt reporting to lead with real (Australian) sessions and orders, and root-caused a broken tracker to an exact one-hour window.

Result: Engagement corrected from 99.9% to 55.7% (64.6% for real Australian traffic); reports are now trustworthy for decision-making.
